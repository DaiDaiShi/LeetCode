# 比特币四年周期：阶段判别

回答一个问题：**现在是爆发前、爆发中，还是四年周期已经不成立了？**

代码给出三样东西：一个阶段后验概率、一个置信度、以及一个"周期到底还存不存在"的统计检验。第三样最重要——前两样只有在第三样通过时才有意义。

```bash
pip install -r requirements.txt
python -m btc_cycle.report                 # 联网抓数据并输出判断
python -m btc_cycle.report --csv my.csv    # 离线，用你自己导出的数据
python -m btc_cycle.report --self-test     # 合成数据自检，不需要网络
python -m btc_cycle.report --backtest      # 各阶段判定对应的真实前瞻收益
```

---

## 一、先把三个问题分开

大部分关于"周期阶段"的讨论把三件事混成一件，导致答案必然含糊：

| 问题 | 性质 | 能不能答 |
|---|---|---|
| 现在的估值位置有多高？ | 描述性 | **能**，而且相当可靠 |
| 接下来会涨还是会跌？ | 预测性 | 很弱，远弱于指标看上去的样子 |
| 四年周期这个结构还在不在？ | 结构性 | 数据量根本不够定论 |

第一个问题用 MVRV、Mayer、200 周均线就能答得很好——因为这些指标**本身就是价格的函数**，它们"高度相关"是恒等式，不是发现。

第二个问题才是你真正想问的，而它的难度高一个量级。

第三个问题是本仓库花最多力气处理的，因为如果答案是"不在了"，前两个问题的框架就整个塌了。

---

## 二、信号清单

按**它能回答哪个问题**分层，而不是按流行程度。

### A. 估值/位置类 —— 答"在哪"，不答"去哪"

这些几乎全是价格的确定性变换，所以和价格同期相关系数极高（0.9+），但这个相关性不含任何增量信息。

- **MVRV**（市值/已实现市值）—— 单指标里刻画周期位置最强的。历史上 Z-Score > 7 见顶、< 0 见底
- **Mayer Multiple** = 价格 / 200 日均线，> 2.4 属历史前 5% 过热区
- **200 周均线倍数** —— 历史上熊市低点极少有效跌破 200 周均线
- **NUPL**（未实现净盈亏）—— > 0.75 欣快，< 0 投降
- **已实现价格倍数** —— 全市场平均成本基础，底部的硬地板
- **Pi Cycle Top**（111DMA 上穿 2×350DMA）—— 2013/2017/2021 三次顶部误差都在 3 天内

**Pi Cycle 必须打个星号**：它是两条均线的交叉，参数 111 和 350 是在同一批数据上挑出来的，样本量 3。它极可能是精致的过拟合。代码里把它当成一个普通信号纳入复合指数，不给它任何特殊地位。

### B. 周期时钟类 —— 答"时间上走到哪"

- **距减半天数**。历史上减半到顶：**371 天 / 526 天 / 548 天**（2012、2016、2020 三次减半）
- **距上一轮周期低点天数**。低点到顶：**747 天 / 1068 天 / 1061 天**

减半到顶的三个数字在**单调变大**；而低点到顶在第二轮跳升后就基本持平。两个时钟给出的"周期在不在拉长"结论并不一致——这本身说明用哪个锚点不是无关紧要的选择，而三个观测不足以判定该选哪个。

代码的 analog 模块用 DTW 做**弹性对齐**而不是刚性叠图，就是因为这个不确定性。

### C. 筹码/行为类 —— 答"爆发前 vs 爆发中"最有用

这一类是**非价格衍生**的，所以才有真正的增量信息：

- **长期持有者供应量（LTH Supply）** —— 顶部前数月 LTH 持续派发给新进者
- **LTH-SOPR** —— 长期持有者的获利了结倍数
- **稳定币总供应量增速** —— 最好的"燃料表"，代表场内待投入的购买力
- **交易所余额变化**
- **已实现市值净流入** —— 真实新增资金，而非估值重估

### D. 杠杆/结构类 —— 答"爆发中"的过热程度

- **永续合约资金费率**滚动均值
- **未平仓量 / 市值比**
- **期权偏斜（skew）**

### E. 宏观流动性类 —— 近年权重大幅上升

- **全球 M2 同比**，常被引用的领先期约 70–100 天。但这个滞后长度本身是在同一批数据上挑出来的，换个样本区间就会漂移——当作量级参考，别当作参数
- **美元指数 DXY**、**实际利率**
- **现货 ETF 净流入**（2024 年后的新变量）

### F. 情绪类 —— 弱，仅在极值处有用

- Fear & Greed、Google Trends

### 最要紧的一句话

A 类（Mayer、MVRV、NUPL、Pi Cycle、200 周均线）**全部是价格的变换**。把它们堆在一起做"多指标共振"，你堆的是同一个变量的七个马甲，自由度只有一个。真正独立的信息来自 **C、D、E** 三类——矿工收入、稳定币供应、ETF 流、M2、交易所余额、LTH 行为。

代码里 `COMPOSITE_SIGNALS` 刻意保留了一批 A 类信号，因为它们确实是最好的**位置**描述；但 `predictive_test` 检验的是时钟类信号在**价格动量基线之外**还有没有增量预测力——这两件事必须分开量化。

## 三、算法

五个模块，各自回答不同的问题。

### 1. 复合热度指数 · `models/composite.py`

把每个信号做**因果分位数**变换（只用截止当天的历史），取平均。透明、无参数、难以骗自己。

用分位数而不是 z-score，是因为 MVRV / Mayer / Puell 的右尾很肥且**每轮周期在缩小**——用 2013 年数据算出的 z-score 会把 2021 年判成"不热"。

热度指数是对称的：0.5 在上行途中是"爆发前"，在下行途中是"爆发后"。所以 `with_direction()` 额外带上斜率和回撤来破这个对称性。

### 2. 高斯 HMM · `models/regime_hmm.py`

这是把"现在是哪个阶段"变成**概率**而不是感觉的模块。4 个隐状态，特征是 90/365 日收益、已实现波动率、回撤、log Mayer、log 200 周倍数。

两个实现细节比模型选择本身更重要：

- **只用前向滤波概率，不用平滑概率。** `hmmlearn` 的 `predict_proba` 返回 P(状态_t | 全部数据)，在历史行上"全部数据"包含了未来。这样读出来的 HMM 会"精准"逃顶每一次。`filtered_probabilities()` 只跑前向递推。
- **滚动窗口重训。** 全样本拟合的模型在标注 2015 年时已经见过四轮周期。`walk_forward()` 每 180 天用当时可得的数据重新估计。它的成绩单难看得多，也是唯一有意义的那份。

还能从转移矩阵读出**状态预期剩余时长** = 1/(1−p_ii)，用来判断"爆发中还能持续多久"的数量级（周？季度？）。注意几何分布是无记忆的，这是量级参考不是倒计时。

### 3. DTW 周期类比 · `models/analog.py`

把当前周期和历史三轮做**弹性时间对齐**，估计"看起来走到了历史周期的百分之几"。

这是加密推特上"周期叠图"的严肃版本，两点不同：对齐是弹性的（周期在拉长，刚性叠图按构造就是错的），而且输出带离散度。

**读离散度，不要读均值。** 三轮周期的振幅是 560×、128×、22×，平均它们没有意义。代码里这个模块**不参与投票**，只作为背景信息输出。

### 4. 监督分类 + 诚实验证 · `models/supervised.py`

在这些特征上训个分类器，随机 K-fold 交叉验证能到 ~90% 日频准确率。这个数字有两重虚假：相邻交易日几乎是同一个样本（测试集就在训练集里），而且随机分折意味着模型见过它正在被打分的那轮周期。

`leave_one_cycle_out()` 是值得看的版本：用完整周期训练，预测留出的那一轮。它同时报告**有效样本量 = 3**。

`random_kfold_for_contrast()` 故意把虚高的数字也算出来，让差距可见。

### 5. 周期存在性检验 · `models/cycle_test.py`

四个互相独立的角度：

**（a）谱检验，AR(1) 红噪声零假设。**

这里有个陷阱值得单独说：做代理检验（surrogate test）的标准配方是**相位随机化**（phase randomization / AAFT）。但相位随机化**精确保留振幅谱**，所以任何由功率谱算出的统计量对数据和代理完全相同，检验功效恒为零。

我第一版就是这么写的，合成数据自检直接暴露了：植入了真实周期的序列，p = 0.778。正确的零假设是拟合的 AR(1) 过程——同样的持续性，没有周期。换掉之后：有周期 p = 0.000，随机游走 p = 0.990。

`test_phase_randomisation_would_have_had_no_power` 这个测试把这个坑永久钉在了仓库里。

**（b）功效分析。** `spectral_power_analysis()` 往匹配真实序列的 AR(1) 噪声里植入已知振幅的周期，统计检出率。

这个数字决定了"没检出周期"到底是"没有周期"还是"数据不够"。16 年数据只有 4 个周期，功效很低——所以多半是后者。**这个区别是整个问题的核心。**

**（c）减半相位锁定检验。** 把前瞻收益按距减半天数折叠分箱，检验箱间方差是否超过零假设。零假设用**循环平移**：完整保留收益序列的全部自相关，只破坏它与减半的对齐关系——正好是被检验的那个假设。

**（d）振幅信噪比。** 每轮周期低点到顶部的年化漂移 ÷ 年化波动率。当漂移不再超过约 1 个标准差，即使周期真实存在也不再值得交易。

### 6. 新颖性检测 · `models/novelty.py`

所有模型都以过去三轮周期为条件。如果今天的市场不像历史上任何时候，那么"阶段判定"就是伪装成分类的外推，**正确答案就是你问的第三个分支**。

- `mahalanobis_novelty()` —— 当前特征向量离历史分布有多远（捕捉前所未有的**水平**）
- `likelihood_novelty()` —— HMM 觉得最近这段有多不可能（捕捉熟悉水平上前所未有的**动态**）

两者会有分歧，而分歧本身是信息。

### 组合 · `ensemble.py`

等权平均，然后做置信度折减：模型分歧大 → 打折；新颖性触发 → 再对折；周期检验不显著 → 再对折。

**不学习组合权重**——在三轮周期上拟合权重，就是用三个观测拟合三个参数。

## 四、六个必须避开的坑

按踩中后损失从大到小排：

1. **全样本归一化泄漏未来。** 几乎所有公开的"周期顶部指标"都用全部历史算 z-score 或分位数，意味着 2013 年的读数用到了 2021 年的数据。必须用 expanding window。本仓库所有变换都是因果的，并有测试守着（截断输入后，存活行的数值必须一字不变）。

2. **HMM 的 `predict_proba` 是平滑概率。** 见上。

3. **时间序列上的随机 K-fold 是作弊。** 必须 leave-one-cycle-out。

4. **相位随机化代理对谱检验零功效。** 见上。

5. **红噪声本身就长得像周期。** 任何持续性强的趋势序列，周期图在低频都有肥大的峰。不跟合适的零假设比，就是在自己骗自己。

6. **n = 3。** 整个"四年周期"理论的全部证据是三个完整周期。任何声称 85% 准确率的模型，其有效样本量是 3。这不是可以靠更多日频数据解决的问题——日频数据增加的是分辨率，不是独立观测数。

## 五、那么周期还在吗？

我的判断：**不要问"现在是周期的哪个阶段"，改问"当前估值位置 + 流动性方向 + 筹码结构"。** 前者预设了一个你没有足够数据去验证的结构；后者每一项都可观测。

支持周期正在弱化的结构性论据：

- **减半的机械冲击已接近噪声。** 2012 年减半后新增供给约占流通量 **12.4%/年**，2024 年减半后约 **0.83%/年**。供给侧的边际影响不再能单独驱动一轮牛市。
- **振幅在衰减。** 低点到顶部倍数 **567× → 129× → 21.6×**。log 振幅近似线性衰减，外推到第四轮是个位数倍。
- **回撤在变浅。** −93%（2011）→ −87% → −84% → −78%。
- **减半到顶在拉长。** 371 → 526 → 548 天。
- **边际买盘性质变了。** 现货 ETF 之后，增量资金来自资产配置流，其节奏跟随宏观流动性周期，而不是减半时钟。

统计上的论据则是：4 个周期的样本量，对检验一个 4 年周期而言功效极低。所以**"没检出"和"不存在"完全不是一回事**，代码里的功效分析会把这个区别量化给你看。

`--self-test` 在与真实序列匹配的噪声上给出的功效表（约 3 个周期的数据量）：

| 周期 log 振幅 | 峰谷倍数 | 检出率（功效） |
|---|---|---|
| 0.20 | 1.5× | 24% |
| 0.40 | 2.2× | 40% |
| 0.80 | 5.0× | 88% |
| 1.20 | 11.0× | 100% |

读法：**峰谷倍数要到约 5×，这么点历史数据才有 ~88% 的把握能把周期认出来。** 一个 2.2× 的周期只有 40% 功效——抛硬币都比这强。

把这张表和上面的振幅衰减放在一起看，就是整件事的要害：前三轮周期的振幅（567×、129×、21.6×）远在可检出区间之上，所以"过去存在四年周期"这个结论是稳的。但如果第四轮衰减到个位数倍，它正好落在这张表的**功效悬崖上**。

换句话说：周期即使还在，也正在进入**统计上无法与噪声区分**的区间。对判断"现在是爆发前还是爆发中"而言，这比"周期是真是假"的哲学争论重要得多。

这个态度被编码进了 `ensemble.py`：周期检验不显著或新颖性触发时，置信度直接对折。宁可输出"我不知道"，也不输出一个好看的假数字。

## 八、仓位：long 还是 short

`position.py` 把阶段后验转成目标敞口。核心不是"怎么下单"，而是**什么时候拒绝下单**。

```bash
python -m btc_cycle.report --position     # 敞口建议 + 各阶段样本外收益
python -m btc_cycle.report --strategy     # 走样本外策略 vs 买入持有（含成本）
python -m btc_cycle.report --hurdle-only  # 做空门槛算术，完全不需要行情数据
```

### 做多和做空的证据门槛不对称

比特币的无条件漂移又大又正。做多是顺着漂移下注，做空是逆着。所以把 `P(熊市)=0.6` 和 `P(牛市)=0.6` 当成镜像对待的模型，会做空得太频繁。

用真实周期锚点算出的低点到低点年化漂移：

| 区间 | 年化 |
|---|---|
| 2011-11 → 2015-01 | +136% |
| 2015-01 → 2018-12 | +78% |
| 2018-12 → 2022-11 | +40% |
| 中位数 | **+79%** |

（低点到顶部的区间读数在 +106% 到 +310%，但那是拿四年里最高的一个价格做锚，系统性偏高，不能用。）

漂移在逐轮衰减，取最近一轮的 **+40%/年**、波动率 **50%/年** 作保守假设。做空的盈亏平衡是：

```
条件预期收益 < 资金费(+10%) - 成本(2%) = +8%/年
```

也就是说，信号必须把预期收益从 +40% 拉到 +8% 以下——**要位移 32 个百分点**。而每个阶段的独立观测只有 5–9 个，标准误是 `50%/√8 ≈ 18%`。我设的门是"点估计 + 2 个标准误仍要低于盈亏平衡"，于是：

| 有效样本量 | 标准误 | 需要的点估计 |
|---|---|---|
| 3 | 29% | **< −50%/年** |
| 5 | 22% | **< −37%/年** |
| 8 | 18% | **< −27%/年** |
| 12 | 14% | **< −21%/年** |

### 门槛过得去吗？过得去

历史熊市腿实际跌幅（顶到底）：

| 熊市腿 | 时长 | 回撤 | 年化 |
|---|---|---|---|
| 2013-12 → 2015-01 | 1.11y | −86.9% | **−183%** |
| 2017-12 → 2018-12 | 0.99y | −83.8% | **−183%** |
| 2021-11 → 2022-11 | 1.03y | −77.6% | **−145%** |

中位数 −183%/年，门槛 −27%/年，**余量 155 个百分点**。

所以做空的问题**不在算术上**。它完全取决于一件事：走样本外的阶段判定能不能**足够早、足够干净**地认出熊市腿，从而吃到其中可用的一部分。上表是"完美探测器"的天花板，不是期望值。

### 而这正是坏消息所在

在**周期真实存在**的合成数据上跑走样本外策略（含手续费和资金费）：

| | 总倍数 | 年化 | 夏普 | 最大回撤 |
|---|---|---|---|---|
| 阶段择时策略 | 4.57× | +19.8% | 1.62 | −42.1% |
| 买入并持有 | **13.33×** | **+33.8%** | **1.94** | −76.9% |

**周期是真的，策略仍然输给买入持有**——总收益和夏普双输，只在回撤上赢。平均敞口 0.49，也就是有一半时间在场外，而场外的代价在一个高速复利的资产上极其昂贵。允许做空后总倍数从 4.57 变成 4.70，基本没动。

这不是参数没调好。这是"阶段判定的样本外精度"和"漂移"之间的量级关系决定的。

### 所以默认姿态

代码把这个结论编码成了硬约束：

- **最大做空敞口 −0.25**，无论信号多强（`MAX_SHORT`）
- 做空必须过 `short_hurdle` 的双标准误门，否则强制归零
- 周期检验不显著 → 敞口减半；新颖性触发 → 再减半
- Kelly 值在乘置信度**之前**先裁剪，否则低波动下置信度折减会被最终裁剪吞掉，形同虚设

落到实操上：**长期偏多、在高热度区减仓、基本不做空**，是这套分析支持的姿态。想做空就得拿出比"阶段模型说是熊市"强得多的东西——比如已经确认的结构破位加上流动性指标同向，而且要接受它大概率跑不赢单纯少拿一点仓位。
